# Harbor Field Guide

[Read the guide](https://ayushnangia.github.io/harbor-field-guide/)

A visual walkthrough of how Harbor takes a task, runs an agent in a sandbox, verifies the work, and records the result. It also explains where datasets, adapters, Rewardkit, regrading, and Harbor Index fit.

Use the table of contents to follow a run from start to finish, or search for a specific concept. Each section links to the relevant [Harbor documentation](https://docs.harborframework.com/) for commands and details.

The site is plain HTML, CSS, and JavaScript. To view it locally, open `index.html` in a browser. There is no build step.
